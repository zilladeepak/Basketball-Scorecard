# 🏀 Basketball Scorecard

An interactive Basketball Scorecard web application built using **HTML**, **CSS**, and **JavaScript**.  
This project allows users to track basketball game scores in real time through a clean and responsive user interface.

## 📌 Features

- Live score tracking
- Separate score controls for both teams
- Clean and responsive UI
- Instant score updates using JavaScript
- Beginner-friendly project structure
- Lightweight and fast-loading application

---

## 🛠️ Built With

- **HTML5** — Structure of the application
- **CSS3** — Styling and layout
- **JavaScript (Vanilla JS)** — Dynamic score functionality
